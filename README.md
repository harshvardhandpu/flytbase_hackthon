# ScoutOS

ScoutOS is an AI-native BDR operating system. It coordinates specialised agents for research, qualification, outreach, inbound handling, and pipeline intelligence while keeping humans in control of consequential actions.

This repository currently contains **Phase 1: foundation only**: documentation, provider-neutral AI interfaces, database models and migrations, agent contracts, and configuration. No production agent workflows or UI are implemented yet.

See [docs/PROJECT_OVERVIEW.md](docs/PROJECT_OVERVIEW.md) before contributing.
